## What I work on

- **Observability & reliability:** metrics, logs, alerting, troubleshooting, backup and recovery.
- **Platforms & delivery:** Kubernetes, GitOps, reusable CI/CD pipelines, and repeatable deployments.
- **Automation & AI integration:** practical scripts, APIs, and Model Context Protocol (MCP) tools.
- **Docs-as-Code:** documentation and diagrams in Git, reviewed changes, and automated publishing.
